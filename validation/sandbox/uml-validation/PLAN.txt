UML validation goal — 2026-10-21

Trust boundary: the entire UML kernel, initramfs and recipe are untrusted.
The outer kernel and conglobate supervisor enforce confinement and own inventory.
No runner report or console marker establishes security or recipe honesty.

Completion criteria: reproducible tests and retained evidence for every item;
explicit failures are valid findings, but unexecuted tests are not passes.
Design acceptance requires isolation and functional requirements to pass or an
explicit user decision on a demonstrated limitation. No exploit code is needed.
Do not mount command-controlled output filesystems in the supervisor kernel.

Required matrix (initial status pending unless stated):
01 Outer confinement: hostfs and management facilities limited to exposed files.
02 Resources: clean env/FDs; private processes; no control over owned supervisor.
03 Storage: actual carapace snapshot handoff; independent output verification.
04 Filesystems: ext4, XFS, Btrfs mount/write/unmount/check.
05 Metadata: IDs, modes, links, ACLs, capabilities, devices, sparse, xattrs, flags.
06 SELinux: foreign labels persist; produced image boots its policy enforcing.
07 Network: enabled egress/DNS/return traffic; disabled none; no inbound service.
08 Lifecycle: success/failure/crash/cancel/timeout/supervisor loss, no leftovers.
09 Limits: bounded memory/process/storage/log exhaustion preserves supervisor.
10 Output: false success/missing/truncated/unclean output cannot forge inventory;
   acceptance checks defined and output parsing confined.
11 Concurrency: distinct resources, cancel one without disrupting other.
12 Deployment: repeat representative suite inside actual build VM environment.
13 Workloads: Fedora, Debian, Alpine, NixOS bootstrap and layer changes;
   firmware kernel/initramfs/artifact generation; cross-step persistence.
14 Performance: boot, flush/shutdown, memory, package/metadata/kernel work versus
   native baseline. Prior minimal boot baseline ~0.95s readiness, ~1.01s total;
   does not qualify nested deployment or build throughput.

Prototype bubblewrap usage tests Linux confinement primitives. It does not
select the production runtime. Existing FUSE findings do not count as UML tests.
All tests use owned disposable artifacts; host security configuration unchanged.
