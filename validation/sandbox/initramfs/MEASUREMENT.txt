Restricted Fedora workload measurement
=====================================

Run two to five serial, fully checked builds using the same provisioned inputs:

  python3 validation/sandbox/initramfs/measure.py \
    --seed /tmp/conglobate-rebuilt-package-seed-v2 \
    --upgrade-rpms /tmp/conglobate-upgrade-rpms \
    --protocol-worker-build /tmp/conglobate-acl-protocol-v5 \
    --initramfs-rpms /tmp/conglobate-initramfs-rpms-v1 \
    --out /tmp/NEW-MEASUREMENTS

The output directory must not exist. Each build gets a fresh 2-vCPU, 8192-MiB
guest. Host caches are not flushed. The package runner has a 300-second guest
timeout; the measurement wrapper has a 480-second timeout for each entire run.
Do not count a timeout or failed build as a successful performance result.

Runner wall time includes packaging, VM launch, the full package/initramfs
fixture, verification and teardown. Guest uptime comes from the kernel reset
timestamp. Neither quantity isolates package-manager or dracut performance.
The fixture also exercises control probes and intentional worker failure after
the successful build. No kernel-filesystem comparison is performed. Two runs
provide a baseline, not a statistically characterized performance distribution.

Each successful measurement requires the package runner's strict checks and
exactly one successful guest exit, plus explicit ACL, final kernel-remount and
overall-validation markers. The runner rejects known dracut/GRUB errors; its
README documents remaining nonfatal package warnings and boot-policy choices.
Independent boot validation is a separate test, not implied by this timing run.

Retain measurements.json, summary.json, per-run command.json, inputs.json,
results.txt and runner logs. Compare all file hashes and symlink targets in the
two inputs.json catalogs before describing the inputs as identical. Keep the
worker build-input catalog and measurement/runner source snapshots alongside
the results. These catalogs describe reproduction inputs, not attestation.
Do not retain generated VM archives or exported firmware in the repository.
