Before v44, cargo check caught E0382: a map_err closure moved the process wait owner even on the successful path, so the following wait_until could not use it. Replaced that closure with an explicit match, transferring the process only in the error branch. No VM run used the rejected source. The initial compiler diagnostic was observed in the tool output, not captured as a raw file; this note records the failure and correction rather than claiming a saved stderr transcript.
