# Retained acceptance evidence

These are selected immutable reports from the full archive described in
ARCHIVE.md. Historical `preservation/`, `validation/`, `/tmp` and `/var/tmp`
references inside them locate archived source/evidence; they are not missing
active implementation modules. Older milestone reports retain their original
scope and date. REIMPLEMENTATION.md and QUALIFICATION.md state current acceptance.

Raw review streams, every experimental harness/patch, failed attempts, source
snapshots, committed contexts and large output artifacts remain in the archives.
The Git bundle preserves their complete committed history. These small selected
records support review without keeping retired implementation/experiments active.

Build-only verdicts can say `boot_passed: false`; the later boot verdict and raw
console marker establish the separate boot result. `full_distro_qualified: false`
and similar historical flags are intentional: representative workload success
is not universal compatibility or a confidentiality claim.
